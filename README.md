# Kommentar till skadeståndslagen (1972:207)

Kommentar till svensk författning: **Skadeståndslag (1972:207)** (SFS 1972:207). Kommentaren omfattar **39 enheter** (38 paragrafer i lagens 1–6 kap., varav de upphävda 1 kap. 3 § och 3 kap. 10 §, samt övergångsbestämmelserna) fördelade på 2 kommentarskapitel; vid varje enhet återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 2026:1207** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2026-09-08).

Källa: [rkrattsbaser.gov.se/sfst?bet=1972:207](https://rkrattsbaser.gov.se/sfst?bet=1972%3A207) · [data.riksdagen.se/dokument/sfs-1972-207](https://data.riksdagen.se/dokument/sfs-1972-207.json)
